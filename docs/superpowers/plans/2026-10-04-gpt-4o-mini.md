# GPT-4o mini Integration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Add a strictly validated, budget-controlled historical LLM strategy with blindfolded inputs and exact offline replay.

**Architecture:** A provider-neutral strategy consumes sanitized Context payloads and returns existing Decision objects. Separate provider, budget and cache components preserve audit evidence. CLI/storage integrate these without changing the deterministic risk and execution engine.

**Tech Stack:** Existing Python 3.13 project, standard-library HTTPS/json/sqlite3/hashlib, pytest; no new production dependency required.

**Spec:** ../specs/2026-10-04-gpt-4o-mini-design.md and ../../../LLM_TRADING_AGENT_BACKTEST_SPEC.md.

## Global Constraints

- Model ID `gpt-4o-mini`, temperature 0, maximum output 512 tokens, 30-second timeout, and no automatic paid retries.
- Initial experiments share one $10 maximum API budget across SPY and GLD.
- QQQ stays blocked by unresolved dividend payment dates.
- Development remains 2005-2014; walk-forward 2015-2023 and untouched holdout 2024-2025 remain later sequential gates.
- No broker or live execution adapter is included.
- Code supplies the approved 3% stop; confidence does not alter sizing and horizon_bars must be null.
- Complete Phase 5 leakage tests before any paid pilot; first paid pilot has at most 20 daily decisions per asset.
- No journal in primary E2; optional journal variant contains the last 20 past decisions only.
- Repository has no Git history: preserve source archives and do not invent commits or initialize Git as part of this work.

## Review Focus

1. Missing/malformed provider usage after a potentially charged failure must retain the reservation, never falsely release spend.
2. Concurrent processes and crashes must not bypass the shared $10 cap or silently reset it.
3. Identifying or future information inside account/journal strings must never enter model requests.
4. A cache hit from different model settings, account state or prompts must not substitute a different decision.
5. An interrupted/pilot run must never become a full completed comparison; replay must never call the API.

- `llm_trading/llm_contract.py`: configuration, provider response contract and strict decision validator.
